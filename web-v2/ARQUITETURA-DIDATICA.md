# Mapa gráfico dos componentes do AIDP

Versão atual: caminho guiado por Byte, Íris e Atlas. Uma parada por componente e um guia visível por vez. O trajeto do rodapé indica a ordem da explicação, não o fluxo físico de dados.

| Parada | Guia | Função |
|---|---|---|
| Workspace | Atlas | Organizar artefatos e associar recursos |
| Arquivos e conhecimento | Íris | Distinguir volume de base preparada para recuperação |
| Catálogo | Íris | Localizar e entender ativos |
| Compute Spark | Byte | Executar código de processamento |
| Workflow | Byte | Coordenar tarefas e dependências |
| AI Compute | Atlas | Executar agentes que usam modelos e ferramentas |

Avanço manual, movimento do marcador entre paradas, navegação por teclado e preferência de movimento reduzido. Os textos dos guias são falas didáticas, não inferências reais. Os estados de recursos são consultados separadamente, em painel recolhido. Não se executam operações cloud nesta visita.
